# DunkHub — архитектурные решения

## Платформа

Единый веб-фронтенд (React + Vite, PWA), встраиваемый как Telegram Mini App
через `@twa-dev/sdk` / `window.Telegram.WebApp`. Отдельного нативного
приложения нет — Telegram Mini App и standalone PWA используют один и тот
же код. Авторизация в MVP — только через Telegram `initData` (HMAC-проверка
на бэкенде, см. `apps/api/src/telegramAuth.ts`); доступ вне Telegram
(standalone PWA) без Telegram-аккаунта в MVP не поддерживается.

## Замер прыжка

On-device pose estimation (MediaPipe Pose Landmarker, WASM/GPU-delegate),
без отправки видео на сервер. Высота считается по времени полёта
(flight time), которое определяется по вертикальной скорости
условного центра масс (среднее по landmark бёдер) — see `JumpMeasure.tsx`.
Это прототип алгоритма детекции взлёта/приземления, а не финальная
калибровка точности — требует валидации на реальных прыжках и, возможно,
калибровки по росту пользователя перед тем, как показывать пользователю
абсолютные цифры без диапазона погрешности.

Открытый риск: производительность pose-detection внутри WebView Telegram
на среднебюджетных Android-устройствах не проверена — это первое, что
нужно протестировать на реальных телефонах перед тем, как расширять
функциональность замера (approach jump, reactive jump).

## Согласие на использование данных

Согласие — обязательное условие для записи `JumpMeasurement`
(проверяется в `POST /jumps` в apps/api/src/server.ts). Хранится как
версионируемая запись `ConsentRecord` (scope + version + timestamp),
чтобы при изменении политики можно было запросить согласие заново, не
теряя историю прежних согласий.

## Что дальше (не реализовано в этом скелете)

- Тренировочные программы (content service) — намеренно не включены в
  первый скелет, чтобы сначала подтвердить, что замер прыжка вообще
  технически работает в целевой среде (Telegram WebView).
- Injury prevention (asymmetry/ACWR) — зависит от накопленной истории
  замеров, имеет смысл добавлять после V1.
- Community/leaderboard — то же самое, вторичный слой поверх данных.
