# DunkHub — запуск локально

Всё запускается на вашей машине за 5 минут, без деплоя и сторонних аккаунтов.
Камера в браузере на `localhost` работает без HTTPS, так что замер прыжка
можно протестировать прямо через веб-камеру ноутбука.

## Что понадобится

- Node.js 20+
- pnpm (`npm install -g pnpm`, если ещё нет)
- Docker (для базы данных одной командой) — либо локально установленный PostgreSQL 14+

## Шаги

```bash
git clone <url репозитория>
cd dunkhub
git checkout claude/dunkhub-architecture-plan-hjchjg

pnpm install

# База данных
docker compose up -d
# Если нет Docker — поднимите PostgreSQL сами и укажите его адрес в apps/api/.env

cp apps/api/.env.example apps/api/.env
# откройте apps/api/.env и замените JWT_SECRET на любую случайную строку

cd apps/api
pnpm prisma:migrate   # применит схему БД
cd ../..
```

Дальше — два терминала:

```bash
# терминал 1: backend
pnpm dev:api

# терминал 2: frontend
pnpm dev:web
```

Откройте **http://localhost:5173** в браузере (Chrome/Edge — MediaPipe
на них стабильнее, чем в Safari).

## Что можно протестировать сейчас

1. Регистрация (email + пароль) и согласие на обработку данных.
2. **Замер прыжка** — через веб-камеру ноутбука: разрешите доступ к камере,
   встаньте так, чтобы всё тело было в кадре, нажмите «Начать замер» и
   подпрыгните. Точность на этом этапе не откалибрована — оценивайте
   стабильность детекции взлёта/приземления, а не точные сантиметры.
3. **Самочувствие** — дневной чек-ин (боль, сон, RPE).
4. **Прогресс** — рекорд, тренд, ACWR (риск перетренированности), асимметрия
   колен, история замеров.

## Тест на телефоне

Мобильному браузеру, в отличие от `localhost`, нужен настоящий HTTPS, иначе
камера не откроется. Самый быстрый способ без деплоя и регистраций —
`cloudflared` quick tunnel (публичный HTTPS-адрес поверх уже запущенных
`pnpm dev:api` / `pnpm dev:web`, без аккаунта и без токена).

1. Поставьте `cloudflared`:
   - macOS: `brew install cloudflared`
   - Windows/Linux: бинарник со страницы
     [github.com/cloudflare/cloudflared/releases](https://github.com/cloudflare/cloudflared/releases)

2. При уже запущенных `dev:api` и `dev:web` откройте два новых терминала:

   ```bash
   # терминал 3: туннель для backend
   cloudflared tunnel --url http://localhost:3001
   ```

   В выводе будет строка вида `https://random-words-1234.trycloudflare.com` —
   это и есть публичный адрес вашего API. Скопируйте его.

   ```bash
   # терминал 4: туннель для frontend
   cloudflared tunnel --url http://localhost:5173
   ```

   Аналогично получите второй адрес — публичный адрес фронтенда.

3. Пропишите адрес API из шага 2 в `apps/web/.env` (создайте по образцу
   `apps/web/.env.example`):

   ```
   VITE_API_BASE=https://<адрес-из-терминала-3>.trycloudflare.com
   ```

   Перезапустите `pnpm dev:web`, чтобы Vite подхватил переменную.

4. Откройте на телефоне HTTPS-адрес фронтенда из терминала 4. Разрешите
   доступ к камере, встаньте так, чтобы всё тело было в кадре (используется
   тыловая камера), и прыгайте.

Учтите: quick tunnel — публичный URL, доступный любому, у кого есть ссылка,
и живёт, пока открыт терминал. Для разовой проверки это нормально; для
долгоживущего адреса или ограничения доступа понадобится уже настоящий
деплой.
